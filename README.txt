ColorBite POS - installable app
1. Upload ALL files in this folder to any HTTPS host (Netlify Drop, GitHub Pages, Cloudflare Pages).
2. Open the address in Chrome/Edge (PC, Android) or Safari (iPhone/iPad).
3. Install: Chrome/Edge -> "Install app" in the address bar; Safari -> Share -> Add to Home Screen.
Always open the same address on the same device: the sales log is stored per browser and address.
Test on your own PC only: run "python -m http.server" in this folder and open http://localhost:8000
